⌨️ Proxmox Commands Reference

📦 Container Management (LXC)

List all containers Basic
pct list
Start a container Basic
pct start <vmid>
Stop a container Basic
pct stop <vmid>
Enter container shell Basic
pct enter <vmid>
Execute command in container Advanced
pct exec <vmid> -- <command>
Create container from template Advanced
pct create <vmid> local:vztmpl/debian-12-standard_12.12-1_amd64.tar.zst \ --hostname <name> --memory 2048 --cores 2 \ --rootfs local-lvm:20 --net0 name=eth0,bridge=vmbr0,ip=dhcp \ --unprivileged 1 --features nesting=1 --start 1
Resize container disk Advanced
pct resize <vmid> rootfs +10G
Clone a container Advanced
pct clone <vmid> <newvmid> --hostname <newhostname>
Delete a container Danger
pct destroy <vmid> --purge

🖥️ VM Management (QEMU)

List all VMs Basic
qm list
Start a VM Basic
qm start <vmid>
Stop a VM (graceful) Basic
qm shutdown <vmid>
Force stop a VM Danger
qm stop <vmid>
VM configuration Basic
qm config <vmid>
Resize VM disk Advanced
qm resize <vmid> scsi0 +20G

💾 Backup & Restore

Backup a container Basic
vzdump <vmid> --storage local --compress zstd
Restore from backup Advanced
pct restore <vmid> /var/lib/vz/dump/vzdump-lxc-<vmid>-*.tar.zst
List backups Basic
ls -la /var/lib/vz/dump/

🌐 Networking

Show network config Basic
cat /etc/network/interfaces
Restart networking Danger
systemctl restart networking
Get container IP Basic
pct exec <vmid> -- ip addr show eth0

📊 Monitoring

Node status Basic
pvesh get /nodes/proxmox/status
Storage usage Basic
pvesh get /storage --output-format json-pretty
Live resource usage Basic
watch -n 1 'pct list && echo "---" && qm list'

⚡ Optimization & Best Practices

🐳 LXC Container Tips

  • Use unprivileged containers when possible
  • Enable nesting for Docker inside LXC
  • Set CPU limits to prevent resource hogging
  • Use memory limits with swap disabled for predictability

💾 Storage Optimization

  • Use LVM-thin for thin provisioning
  • Enable compression with zstd for backups
  • Schedule backups during low-usage hours
  • Prune old backups regularly

🔐 Security Hardening

  • Use SSH keys instead of passwords
  • Enable firewall on all containers
  • Regular updates: apt update && apt upgrade
  • Disable root SSH on non-essential systems

🌐 Network Best Practices

  • Use static IPs for critical services
  • Segment networks with VLANs
  • Use internal DNS (Technitium)
  • Enable IPv6 only if needed

🖥️ VM Settings

  • Use virtio drivers for best performance
  • Enable QEMU guest agent
  • Use CPU type "host" for passthrough
  • Enable ballooning for dynamic memory

📈 Monitoring

  • Set up Grafana + InfluxDB stack
  • Configure email alerts
  • Monitor disk SMART status
  • Track container resource trends

💾 Backup Strategy

Backup All Running Containers

for id in $(pct list | awk 'NR>1 && $2=="running" {print $1}'); do vzdump $id --storage local --compress zstd --mode snapshot done

Scheduled Backup (cron)

# Add to /etc/cron.d/proxmox-backup 0 3 * * * root vzdump 100 101 102 103 104 105 106 110 111 113 --storage local --compress zstd --mode snapshot --mailto philip@philipwright.me
